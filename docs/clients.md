# Клиенты

## Быстрый выбор

| Платформа | Основной | Запасной | Формат |
|---|---|---|---|
| Android | Hiddify | v2rayNG, Happ, NekoBox | ссылка `vless://` |
| iOS | Streisand | Happ, V2Box, Shadowrocket (платный) | ссылка `vless://` |
| macOS | Streisand | Hiddify, V2Box | ссылка `vless://` |
| Windows | Hiddify | Nekoray, v2rayN, Furious | ссылка или `config.json` |
| Linux | Nekoray | xray-core напрямую | `config.json` |
| Роутер | Keenetic + Entware, OpenWrt | — | `config.json` |

Все перечисленные клиенты бесплатны и с открытым исходным кодом, кроме Shadowrocket.
Устанавливайте из официальных репозиториев на GitHub или из магазинов приложений;
не берите сборки со сторонних сайтов.

## Подключение по ссылке

Скрипт `02-add-client.sh` выдаёт ссылку вида `vless://…` и QR-код.

- **Мобильные клиенты**: нажмите «+» → «Сканировать QR-код» или «Импорт из буфера обмена».
- **Десктопные**: скопируйте ссылку и нажмите «Добавить из буфера обмена».

Одна ссылка — одно устройство. Не используйте один UUID на нескольких устройствах:
это ломает статистику, мешает отзывать доступ и создаёт нехарактерный профиль
подключений с одного ключа.

## Настройка маршрутизации «РФ напрямую»

Это ключевой момент для вашего сценария — доступ и к зарубежным, и к российским
сервисам одновременно.

**Hiddify**: Настройки → Правила маршрутизации → выберите готовый профиль для России,
либо включите «Обход для РФ» (`bypass RU`).

**v2rayNG**: Настройки → Routing → Предустановленные правила → выберите набор,
исключающий российские домены и IP. Проверьте, что в «Обход» попали `geoip:ru`
и `geosite:category-ru`.

**Streisand**: Настройки → Маршруты → включите обход для российских адресов.

**Nekoray / v2rayN / xray-core**: используйте готовый конфиг из комплекта:

```bash
bash scripts/06-gen-client-config.sh laptop
scp root@<IP>:/root/xray-laptop.json .
```

В нём уже прописаны правила: `.ru`, `.su`, `.рф`, российские соцсети и их CDN,
диапазоны `geoip:ru` — напрямую; всё остальное — через сервер.

### Проверка, что split-routing работает

1. Откройте сайт, показывающий ваш IP (например `ifconfig.me`) — должен показать
   **адрес сервера**.
2. Откройте `2ip.ru` или любой российский сервис определения IP — должен показать
   **ваш реальный** российский адрес.
3. Зайдите в интернет-банк — не должно быть запросов на подтверждение входа
   с нового устройства и капчи.

Если банк или Госуслуги требуют подтверждений — значит, их домены идут через VPN
и правила маршрутизации не применились.

## Настройка роутера на всю квартиру

Самый удобный вариант в быту: настроить один раз на роутере, и все устройства
в доме — телевизор, консоль, ноутбуки — работают без клиентов.

### Keenetic

Модели с USB-портом и достаточным объёмом памяти (Giga, Ultra, Hopper):

1. Установите Entware на USB-накопитель через веб-интерфейс (Приложения → OPKG).
2. Подключитесь по SSH и установите xray: `opkg update && opkg install xray`.
3. Положите конфиг из `06-gen-client-config.sh` в `/opt/etc/xray/config.json`,
   заменив в нём `listen` на `0.0.0.0` в секции `inbounds`.
4. Настройте прозрачное проксирование через tproxy или задайте маршрут через
   локальный SOCKS-порт для нужных устройств.

Сохраните возможность отключить туннель без SSH — например, отдельным профилем
Wi-Fi, который идёт мимо прокси. Это спасает, когда что-то ломается.

### OpenWrt

Проще всего через пакеты `luci-app-passwall` или `luci-app-homeproxy` (в составе
сборок ImmortalWrt): оба умеют VLESS + Reality и импорт ссылки `vless://`
прямо в веб-интерфейсе, включая правила обхода для российских адресов.

Требования: не менее 128 МБ RAM и 16 МБ flash, иначе пакеты не поместятся.

### Чего роутер не даст

Мобильные устройства вне дома останутся без защиты — на них всё равно нужен клиент.
Держите оба варианта: роутер для домашних устройств, приложения для телефонов.

## AmneziaWG

Клиент **AmneziaVPN** есть под Windows, macOS, Linux, Android и iOS. Импортируйте
файл `.conf`, созданный скриптом `03-install-amneziawg.sh`, через «Добавить
конфигурацию из файла», либо отсканируйте QR-код из вывода скрипта.

Обычные клиенты WireGuard **не подойдут** — они не понимают параметры обфускации
`Jc`, `S1`, `H1` и подобные.

Раздельное туннелирование настраивается в самом приложении AmneziaVPN
(Настройки → Раздельное туннелирование → добавьте российские сайты в исключения).
