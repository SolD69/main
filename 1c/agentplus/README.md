# Агент Плюс → УТ 11: разбиение заявок по складам

Правки модуля объекта внешней обработки обмена «Агент Плюс: Мобильная торговля» (версия с доработками РОДЕН).
Код с пометками «БЫЛО/СТАЛО» лежит в [`split-orders-by-warehouse.bsl`](split-orders-by-warehouse.bsl).

## Что делает

| Требование | Реализация |
|---|---|
| Одна заявка в Агенте → несколько заказов в 1С, товар по складу группы | `рдн_РазделитьЗаказПоСкладам`: склад строки берётся из `рдн_Продажи.СкладыНоменклатуры`, на каждый склад создаётся отдельный Заказ клиента |
| Заказы записываются текущей датой | `ОбъектДок.Дата = ТекущаяДатаСеанса()` для новых документов; при повторной загрузке дата не меняется |
| Комментарий `#ОбменАгентПлюс ДАТАВРЕМЯ` | `рдн_КомментарийОбменаАгентПлюс`; комментарий агента (если есть) идёт со второй строки |

## Как вставить

1. **Изменение 1** — в `ЗагрузитьДокументЗаказ` заменить строку `ЗаполнитьОсновныеРеквизитыДокумента(...)` на блок с `ДатаДоЗагрузки`.
2. **Изменение 2** — в `ЗагрузитьДокументЗаказ` заменить всё от `КонецЦикла;` после цикла по строкам товаров до `КонецФункции`. Старый блок `//РОДЕН ++ 03.11.2026` удаляется: склад строк теперь проставляет функция разбиения.
3. **Изменение 3** — область `рдн_РазбиениеЗаказовПоСкладам` вставить перед последним `#КонецЕсли` модуля.

## Как работают части

- **Основная часть** — сам загружаемый документ. Она сохраняет GUID заявки из Агент+, поэтому подтверждения и повторная загрузка работают как раньше. Основная часть получает склад из шапки, если по нему есть товар.
- **Дополнительные части** — копии шапки с GUID `MD5(заявка + склад)`. Повторная загрузка той же заявки обновляет эти части, а не создаёт новые.
- Обеспечение, статусы серий, график оплаты, валюта, скидки и сумма считаются отдельно для каждой части.

## Что проверить на копии базы

- Дата отгрузки из Агента может оказаться раньше новой даты заказа. Проверьте, не мешает ли это проведению.
- Если одна из частей не записалась и `ОбновлятьДокументыПриЗагрузке` выключен, повторная загрузка заявки будет пропущена: основная часть уже существует.
- При обратной выгрузке в МУ части уйдут как отдельные заказы.
- Если у заявки сменится «основной» склад (например, удалили из неё товар склада шапки), возможен дубль части.
- В живой базе не проверялись: `ТаблицаЗначений.Скопировать(Структура)`, `ДокументОбъект.Скопировать()` на незаписанном объекте и `ПолучитьHexСтрокуИзДвоичныхДанных` (нужна платформа 8.3.9+).
