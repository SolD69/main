# Программист 1С на hh.ru: что важно, а что нет

Срез на 9 октября 2026. По всей России разобраны описания 1498 вакансий программистов и разработчиков 1С: 54 без опыта, 523 с опытом 1–3 года, 758 — 3–6 лет, 163 — 6+ лет. Зарплата указана в 715 из них.

## Как считалось

- Каждое описание разбито на разделы: «Обязанности», «Требования», «Будет плюсом», «Условия». Раздел «Требования» найден в 94% вакансий, «Будет плюсом» — в 52%. Если строка в «Требованиях» содержит «будет плюсом», «желательно» или «приветствуется», она считается желательной, а не обязательной.
- Для каждого требования посчитаны три доли вакансий:
  - **обязательно** — требование стоит в «Требованиях»;
  - **плюс** — оно есть только в «Будет плюсом»;
  - **упоминается** — оно есть где угодно в описании или в ключевых навыках.
- **Влияние на зарплату** — разница в медианной зарплате «на руки» между вакансиями с упоминанием требования и без него. Сравнение идёт при одинаковом грейде, регионе (Москва, СПб, МО, регионы) и формате работы, через регрессию по логарифму зарплаты. Значимым считается |t| ≥ 2. Это корреляция, а не доказанная причина: «дорогие» требования чаще встречаются у крупных работодателей.
- Требования ищутся по ключевым словам. Шаблоны проверены на случайных выборках, но погрешность в несколько процентных пунктов возможна.

## Главное

1. **Грейд в 1С определяет зарплату сильнее любого навыка.** В сравнении с опытом 1–3 года при прочих равных:
   - без опыта — −46%;
   - 3–6 лет — +31%;
   - 6+ лет — +72%.

   Регион тоже важен: Москва +37%, Санкт-Петербург +16% к регионам. Гибридный формат даёт +11%. Полная удалёнка после учёта региона и грейда значимой прибавки не даёт (+5%, t=1,2).
2. **Обязательных требований немного.** Медиана — 1–2 пункта в вакансиях без опыта, 5 пунктов при опыте 1–3 года и 7 пунктов при 3–6 и 6+ годах. Всего в описаниях упоминается 5, 11, 13 и 13 пунктов соответственно: остальное — задачи и пожелания.
3. **Фильтр опыта на hh.ru завышен.** В 1–3 годах конкретный срок назван в 40% вакансий: «от 1 года» — 76, «от 2 лет» — 59, «от 3 лет» — 64. В 3–6 годах обычно пишут «от 3 лет» (273 из 419). В 6+ годах чаще пишут «от 5 лет» (32) и «от 3 лет» (26), а «от 6 лет» — всего 17. Значит, откликаться можно на грейд выше своего опыта.
4. **Ядро везде одно:** СКД, язык запросов, управляемые формы, БСП, обмены и HTTP-интеграции, ERP/ЗУП/УТ/БП. Само по себе ядро зарплату почти не поднимает (0…+6%). Это обязательный минимум.
5. **Платят больше за инженерные практики и лидерство.** Наставничество и руководство командой — +36%, code review/АПК/SonarQube — +30%, Kafka/RabbitMQ — +25%, EDT — +21%, CI/CD — +21%, проектирование и архитектура — +15%, оценка трудозатрат — +13%. Из отраслей больше платят за производственный учёт (+20%), WMS (+15%), ERP (+12%) и ЗУП (+8%).
6. **Сертификаты почти не влияют.** Чаще всего они в разделе «плюс», а не в обязательных: любой сертификат — 18% против 9%, 1С:Специалист — 10% против 5%. Влияния на зарплату нет: −1% и +3%, оба незначимые.
7. **Есть признаки более низкой зарплаты.** Это Битрикс и сайты (−14%), другой язык программирования (−22%, обычно веб-вакансии вперемешку с 1С), 1С:CRM (−10%), а также «1С + сисадмин» (−14%). Акцент на «обучаемость / желание развиваться» даёт −18%, на «самостоятельность» −8%. Из задач ниже рынка оплачиваются «отчёты и печатные формы» (−8%), «права доступа и администрирование» (−9%) и «обновления» (−6%).
8. **На удалёнку конкуренция в 3–5 раз выше.** Медиана откликов при опыте 1–3 года — 503 на удалённую вакансию против 98 на офисную.

## Что важно по грейдам

### Без опыта (54 вакансии)
- **Чаще всего требуют:**
  - аналитическое мышление (19%);
  - высшее техническое образование (17%);
  - СКД (13%);
  - обучаемость (13%);
  - язык запросов (9%).
- **Часто упоминают:** БП (30%), ЗУП (28%), обновление типовых конфигураций (26%), ERP (20%), обмены (24%).
- **Не нужно:** БСП (0%), Git, CI/CD, архитектура и сертификаты (обязательны лишь в 9%).
- **Работа:** доработки (52%), отчёты и печатные формы (43%), интеграции (44%), проекты (44%). В 11% вакансий кандидату дают наставника.
- **Что изучать:** язык 1С и язык запросов, СКД, обновление типовых конфигураций, основы БП и ЗУП, основы бухучёта. Такой набор закрывает почти все вакансии без опыта.

### 1–3 года (523 вакансии)
- **Обязательно (доля вакансий):**
  - СКД (31%);
  - ERP/КА (24%);
  - обмены (23%);
  - управляемые формы (22%);
  - язык запросов (21%);
  - ЗУП (20%);
  - высшее образование (19%);
  - HTTP/REST (18%);
  - БП (17%);
  - УТ (16%);
  - расширения (15%);
  - «разбираться в чужом коде» (14%);
  - БСП (13%);
  - СУБД (13%).
- **Плюс:** сертификат 1С (18%), 1С:Специалист (9%).
- **Повышают зарплату на этом грейде:** ERP, ЗУП, оптимизация запросов, ТЗ, code review, WMS, УХ.

### 3–6 лет (758 вакансий)
- **Обязательно:** обмены (34%), СКД (33%), ERP (32%), HTTP/REST (32%), ЗУП (26%), управляемые формы (25%), высшее образование (22%), УТ (21%), язык запросов (21%), SOAP (20%), БСП (20%), проектирование (18%).
- **Растёт:** производительность и технологический журнал (упоминаются в 34%), стандарты разработки, code review (13%), Git (13%).
- **Работа:** интеграции (68%), доработки (64%), внедрение (59%), сопровождение (53%), ТЗ и требования (49%), оптимизация (39%), code review (32%), архитектура (31%).

### 6+ лет (163 вакансии)
- **Обязательно:**
  - ERP (44%);
  - HTTP/REST (33%);
  - обмены (31%);
  - архитектура (30%);
  - ЗУП (27%);
  - СКД (25%);
  - УХ (23%);
  - SOAP (20%);
  - СУБД (20%);
  - производительность (18%);
  - бизнес-процессы (18%);
  - проекты внедрения (16%);
  - стандарты разработки (15%);
  - бухучёт (13%);
  - наставничество (10%).
- **Упоминаются чаще, чем на других грейдах:** Git (19%), code review (19%), CI/CD (15%), Kafka (14%), автотесты (9%), EDT (10%).
- **Работа:** архитектура (50%), code review (45%), проекты (68%), руководство (21%).
- **Что отличает от middle:** меньше рутины (отчёты 29%, исправление ошибок 15%), больше архитектуры, ревью, ERP/УХ и проектов внедрения.

## Карта требований: что важно, а что нет

Условные обозначения: М — обязательно, П — будет плюсом. Доли в процентах для грейдов 1–3 и 3–6 лет. Влияние — разница в зарплате при одинаковых грейде, регионе и формате.

| Вывод | Требования (М 1–3 / М 3–6, влияние) |
|---|---|
| **База, за которую ещё и доплачивают** | ERP/КА (24/32, +12%), ЗУП (20/26, +8%), высшее образование (19/22, +9%) |
| **База (must-have)** | СКД (31/33, +2%), обмены КД/EnterpriseData (23/34, +1%), HTTP/REST (18/32, +6%), управляемые формы (22/25, +4%), язык запросов (21/21, 0%), УТ (16/21), БП (17/20), БСП (13/20), SOAP (9/20) |
| **Важно** | расширения (15/15), «чужой код» (14/15), СУБД (13/15), JSON/XML (11/14), Документооборот (7/12), стандарты разработки (7/10), механизмы платформы (6/10) |
| **Повышает зарплату** (встречается реже) | наставничество/руководство +36%, code review/АПК +30%, Kafka/RabbitMQ +25%, EDT +21%, CI/CD +21%, производственный учёт +20%, WMS +15%, архитектура +15%, оценка трудозатрат +13%, проекты внедрения +11%, производительность/ТЖ +9%, ТЗ +9%, техдокументация +9%, клиент-серверная архитектура +8% |
| **Желательно, но не обязательно** | сертификаты 1С (М 9% / П 18%), 1С:Специалист (5/10), 1С:Профессионал (1/4), ЕГАИС/ЧЗ/ЭДО (4/4) |
| **Встречается, но не решает** | УХ, УПП, нетиповые конфигурации, обновление типовых, права доступа, Git, хранилище, администрирование сервера, бизнес-процессы, высшее техническое (против любого высшего), миграции |
| **Редко нужно** (< 8% упоминаний) | УНФ, Розница, БГУ/ЗКГУ, обычные формы, маркетплейсы, торговое оборудование, BI, автотесты, Jira, английский (1–2%), 1С:Эксперт, стрессоустойчивость, многозадачность |
| **Признак более низкой зарплаты** | Битрикс/сайты −14%, другой язык программирования −22%, 1С:CRM −10%, «обучаемость» −18%, «самостоятельность» −8% |

## Файлы

- `requirements_by_grade.csv` — около 80 требований. По каждому: вывод, доли «обязательно», «плюс» и «упоминается» по грейдам, влияние на зарплату и t-статистика.
- `duties_by_grade.csv`, `conditions_by_grade.csv`, `flags_by_grade.csv` — обязанности, условия и тревожные признаки по грейдам.
- `vacancies_1c_programmers.csv` — все 1498 вакансий. Для каждого требования стоит метка «обязательно», «плюс» или «упоминается», для задач, условий и признаков — 0/1. Также есть тексты разделов и описание целиком. Разделитель «;», Excel открывает файл без настройки.
